# Documentation maintenance

Each authoritative document has an owner role and status; directory indexes route readers without duplicating policy. Workflow owners are their stated roles, root instructions/architecture belong to the repository owner with Senior Engineer maintenance. Templates belong to the Senior Engineer with QA/Advisor review.

Review relevant guidance during every PR, at milestone completion and at session handover when assumptions changed. Before the first feature commit, assign a human/agent owner and choose a periodic freshness-review cadence in enforcement readiness; no recurring job is claimed to exist. Future automation should detect stale links, missing owners, contradictions, outdated commands and implementation/documentation drift.

Accepted decisions preserve original rationale. Replace a changed decision with a new numbered ADR, mark the old one superseded, and link both directions. Proposed/accepted/superseded/rejected status is explicit. Specs and plans update with new evidence while preserving decisions in the work-log. Archive is never silently reactivated.

- [ ] Ownership and status identifiable.
- [ ] Replaced decisions linked bidirectionally.
- [ ] Staleness or unknowns recorded with next action.
- [ ] Periodic review owner/cadence tracked when assigned.
